مسار جدول الحصص v0.9.11.2
(الاسم السابق: School Timetable)

أساس هذا الإصدار: v0.9.11.1 (التشخيص المباشر للقيود) مع دفعة الأمان والاستقرار التالية:
- تغيير اسم التطبيق إلى «مسار جدول الحصص». مفتاح التخزين المحلي لم يتغير، فبياناتك الحالية تُقرأ كما هي.
- أي تغيير يُبطل الجدول المولد (التكليفات، قيود المادة، أيام الدوام وعدد الحصص، حصص المراحل) يطلب تأكيداً ويحفظ نسخة استرجاع قبل المسح. عند الإلغاء تبقى القيمة القديمة.
- تعديل اسم المدرس أو المادة ولونها، وإضافة أو حذف مدرس أو مادة بلا تكليفات، لا تمسح الجدول.
- نسخة استرجاع قبل استبدال الجدول بجدول جديد، وتصفير سجل التعديلات اليدوية.
- حذف بيانات مدرسة بعينها من المحرك: قاعدة مدرس محدد، وجدول مرجعي من 692 حصة، وسياسة الثلاثاء في التشخيص. حجم generator-worker.js انخفض من 133KB إلى 15KB.
- أسباب فشل التوليد (نصاب المدرس، سعة الشعبة، تعارض المثبتة) تظهر بأسمائها بدل «نجاح».
- save() لا ينهار عند امتلاء مساحة المتصفح ويُنبّه المستخدم.
- تنقية أسماء الأيام والمراحل، والتحقق من الألوان والشعار وبنية ملف الاستيراد.
- توحيد رقم الإصدار (APP_VERSION) وربط معامل كاش المحرك به، وترقيم الخطوات 1 إلى 15.

ملاحظة: المحرك ما زال يشترط بدء حصص الشعبة من الحصة الأولى، ويكشف التشخيص المباشر هذا القيد كحد وظيفي.
احتفظ بنسخة JSON احتياطية قبل التحديث.
